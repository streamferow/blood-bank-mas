# Ночная вахта банка крови

Многоагентная система, в которой три больницы просят одну дозу и одного курьера. Языковая модель пишет текст заявки. Дозу списывает программа.

Роддом, травматология и онкология видят только фрагмент карты своего пациента. Истинная срочность и склад известны среде. Больница, помеченная в эпизоде как `liar`, получает инструкцию заявить срочность 5 независимо от карты.

## Роли

| Кто | Что делает |
| --- | --- |
| Больница | Возвращает JSON заявки: срочность, группа донора, время в пути |
| Банк | Сортирует заявки и единственный уменьшает склад |
| Арбитр | В споре за последнюю дозу O проверяет цитату и ведёт репутацию |
| Дежурный | В неблагоприятной заявке отвечает `issue` или `hold` |

Сообщение — словарь с полями `performative`, `sender`, `receiver`, `body`. Перформативы: `cfp`, `propose`, `request`, `accept-proposal`, `reject-proposal`, `inform`. Больницы друг другу не пишут. Граф — звезда с банком в центре.

## Совместимость

Резус не учитывается. Донорская группа годится реципиенту, если она есть в его множестве.

| Реципиент | Подходящие доноры |
| --- | --- |
| O | O |
| A | O, A |
| B | O, B |
| AB | O, A, B, AB |

## Каталог `mas/`

| Файл | Содержание |
| --- | --- |
| `cases.py` | Восемь ночей, группы, истинные срочности, таблица совместимости |
| `llm.py` | Вызов модели, разбор первого JSON из ответа, учёт токенов и времени |
| `protocols.py` | Диспетчер и контрактная сеть, общее списание дозы |
| `negotiate.py` | Шесть споров за дозу O: гонка заявок и арбитраж с репутацией |
| `sabotage.py` | Шесть неблагоприятных заявок и повтор с защитами |

### Диспетчер

Больница шлёт `request`. Банк сортирует по заявленной срочности, затем по `eta_min`, затем по имени. За ночь уходит не больше одной дозы: курьер один.

### Контрактная сеть

Банк сначала шлёт `cfp` с остатком. Балл считает код, не модель. Несовместимая группа даёт балл 0 и `reject-proposal`. Иначе

`0.75 * заявленная срочность + 0.25 * (1 - eta_min / 120)`.

Порядок — балл по убыванию, при равенстве имя. Списание делает та же функция, что и у диспетчера.

### Спор

Две больницы, одна доза O. Гонка берёт максимальную заявленную срочность. Арбитраж принимает цитату, только если она дословно входит в карту. Без цитаты потолок срочности равен 2. Репутация начинается с 0.5, переносится между эпизодами и обновляется после выбора победителя. Завышение на два пункта и больше снижает её на 0.25. Принятая цитата поднимает на 0.1.

### Неблагоприятные заявки

Ложная группа, подмена цели, молчащая лаборатория, цикл «роддом → травма → роддом», два приказа «держи» и «выдай», строка, которая притворяется системной инструкцией. С защитой цикл обрывается до вызова модели, строки `SYSTEM` вырезаются, а пара противоположных приказов заменяется на `hold`.

## Запуск

Нужен Python 3.11+ и пакет `openai`.

```bash
python -m venv .venv
source .venv/bin/activate
pip install openai
```

В `.env` рядом с каталогом `mas/` (файл в репозиторий не входит):

```
OPENAI_API_KEY=...
OPENAI_MODEL=gpt-5.4-nano
```

Примеры вызова из корня проекта:

```bash
python -c "from mas.cases import CASES; from mas.protocols import central; print(central(CASES[0])['served'])"
python -c "from mas.negotiate import CONFLICTS, race; print(race(CONFLICTS[:1])[0]['winner'])"
python -c "from mas.sabotage import ATTACKS, run_attack; print(run_attack(ATTACKS[3], True)['action'])"
```

Повторный запуск может изменить отдельные заявки: ответы модели не зафиксированы зерном.
